# 1D-CNN ARRHYTHMIA DETECTOR

## The WHY
Heart attacks occur suddenly without warning, causing tremendous distress to patients and their loved ones. But the warning signs were quietly building up days and even weeks in advance. What if we could catch these warning signs early enough to prevent a heart attack? This project helps by analyzing waveforms recorded by ECG sensors to flag abnormal heartbeats that could signal poor heart health. 

## The WHAT
This project is a heartbeat classifier to detect abnormal heartbeats that signal poor heart health, such as arrhythmias. I used the MIT-BIH dataset to train my model. The model takes raw ECG signal (waveform) data and predicts what a heartbeat likely signals among these 5 categories: "Normal", "Supraventricular", "Ventricular", "Fusion", and "Unknown".
